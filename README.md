# Basic Cutter

An editor-only level design tool for Unity 6. Place a window, door or niche into a wall and Basic Cutter cuts its exact shape out of the wall mesh, fills the opening's inner faces, and keeps the original mesh so every cut can be reverted.

- Works with the Built-in pipeline, URP and HDRP (it only produces meshes).
- Editor only: adds no code or cost to your game build.
- Works with prefabs, prefab instances and plain scene objects, on flat and curved walls.

## Features

- **Exact cuts:** the hole follows the outline of your window model. Box, Arch, Circle and Custom Mesh shapes are also available.
- **Doors:** the opening reaches the floor without a threshold strip and never cuts the floor below.
- **Niches:** a recess of a given depth in one face instead of a hole through the wall.
- **Merged openings:** overlapping cutters form one opening (for example a door with a side light).
- **Surfaces:** a separate jamb material, plus generated trim and sills that follow curved walls.
- **Fast:** only the region around the cutter is recomputed, and large walls are cut on a background thread.
- **Clean results:** the mesh stays watertight, and normals, UVs and materials are preserved.
- **Storage:** cut meshes are embedded in the scene or prefab by default, so no extra files are needed.

## Install

1. Download `BasicCutter-v*.unitypackage` from the [latest release](https://github.com/klardac/BasicCutter/releases/latest).
2. In Unity: **Assets > Import Package > Custom Package...** and import it. No other packages are required.
3. Try **Tools > Basic Cutter > Create Demo Scene**, or add **Basic Cutter > Mesh Cutter** to your window prefab and move it into a wall.

Requires Unity 6 (tested with 6000.3). Walls must be closed (watertight) meshes. Imported models need **Read/Write** enabled.
